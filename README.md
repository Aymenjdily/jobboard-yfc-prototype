# Youth for Challenge — Virtual Job Fair

Front-end prototype built from the designer's screens in `design/`, using fake data only (no backend, no auth).

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npx tsc --noEmit
npm run build
```
